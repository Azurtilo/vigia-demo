# VIGIA móvil

Cliente Flutter Android/iOS para la API del proyecto Django existente.

[Guía de instalación, cuentas demo y pruebas](../docs/MOVIL_DESARROLLO.md).
[Requisitos y alcance](../specs/010-aplicacion-movil/spec.md).
[Resultados y pendientes](../specs/010-aplicacion-movil/validation.md).

Código: `lib/api.dart` (sesión/transporte), `lib/main.dart` (acceso), `lib/care.dart` (agenda, pacientes, postura, historial y capacidades). `web/` permite una vista previa local; Android e iOS son los objetivos móviles.
